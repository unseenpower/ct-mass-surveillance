!!! warning "Please don't post anyone's personal details"

    This site removes the names of private residents from the meeting record.
    Please help keep it that way: on GitHub, don't name private individuals or

    own. If a page on this site identifies a private person, **email us** with
    the link rather than repeating the details in public, and we'll take it
    down.
